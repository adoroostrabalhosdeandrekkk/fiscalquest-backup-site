INTEGRAÇÃO PESSOAL · GOOGLE DRIVE

Uma cópia segura para continuar de onde parei.

FiscalQuest Backup é uma configuração de uso pessoal para preservar cópias de segurança do progresso de estudos do FiscalQuest, utilizando o Google Drive como armazenamento externo.

Como os dados são protegidos →

Integração de uso individual em preparação. Este site é informativo: não recebe login do Google nem arquivos de backup.

FUNCIONAMENTO

O caminho dos dados

01

Cópia local

O computador que executa o FiscalQuest gera cópias do banco de dados e dos arquivos associados às questões.

02

Criptografia

A configuração planejada utiliza o rclone crypt para criptografar o conteúdo e os nomes dos arquivos antes do envio.

03

Armazenamento externo

As cópias criptografadas são enviadas a uma pasta do Google Drive controlada pelo titular da conta.

ACESSO À CONTA

Por que solicitar permissão ao Google?

A autorização OAuth permite que o rclone, executado no computador do proprietário, crie e gerencie os arquivos de backup no Google Drive. A integração foi projetada para utilizar o escopo drive.file, limitado aos arquivos autorizados ou criados pelo aplicativo, sem solicitar acesso irrestrito a todo o Drive.

Esta página pública não hospeda os backups, não executa autenticação OAuth e não precisa receber seus dados pessoais.

Veja a Política de Privacidade para saber como os dados são acessados, utilizados, armazenados e excluídos.
